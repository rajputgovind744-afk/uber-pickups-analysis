# Uber Pickups Analysis

Analysis of Uber pickups data in New York City (April 2014) using Python.

## What I Did
- Cleaned and explored Uber pickups dataset
- Analyzed pickups by day, hour and location
- Created visualizations to find peak hours and busy areas

## Tools Used
- Python
- Pandas
- Matplotlib / Seaborn
- Google Colab

## Dataset
Uber Pickups in New York City - April 2014

## How to Run
1. Open `uber_raw_data_apr14_project.ipynb` in Google Colab
2. Run all cells

## Key Insights
- Evening hours have the highest number of pickups
- Weekdays show more demand than weekends
- Manhattan area has the most pickups
